## 0.1.0

### Minor Changes

- 0221828: First release. plainslides is a headless library for HTML slide decks that AI agents can build: navigation, step reveals, slide transitions, scaling, a presenter window, timing, overview, themes, fullscreen, and print. A deck is one HTML file plus `plainslides.iife.js` and works from `file://`.
